# Asistente ONG — plan integral

## Producto
- Expediente único: caso + informe social + análisis + intervención + derivaciones + seguimiento.
- UI clara, lateral, sin casos ficticios.
- Offline-first; internet solo como complemento controlado.

## Motor
- Contexto antes que palabras aisladas.
- Negación y frases completas.
- Indicadores positivos y negativos.
- Información faltante.
- Confianza orientativa.
- Explicación de por qué se clasificó.
- Revisión profesional obligatoria.

## Argentina
- Jurisdicción nacional/provincial/municipal.
- Recursos con fuente, jurisdicción y fecha de verificación.
- No inventar teléfonos, organismos ni normativa.

## Expediente
- Estados controlados.
- Timeline.
- Tareas.
- Derivaciones.
- Cierre y reapertura controlados.

## Memoria
- Biblioteca local.
- Búsqueda por texto, categoría y jurisdicción.
- Fuentes trazables.
- Versionado y fecha de consulta.
- Futuro índice semántico offline.

## Privacidad
- Minimización.
- Vista anonimizada.
- Auditoría.
- Futuro cifrado de datos en reposo.

## Calidad
- Tests unitarios.
- Tests de regresión del motor.
- Smoke test de arranque.
- Build Windows.
- Prueba en instalación limpia.

## Entrega final
- PDF/DOCX.
- Instalador.
- Actualización segura.
- Backup/restore.
- Manual de uso.
- Modo capacitación sin datos reales.
