# Contrato funcional de botones

Toda acción visible debe producir un cambio, abrir una vista o ejecutar una consulta. No se permiten botones decorativos con apariencia de acción.

| Sección | Acción | Resultado |
|---|---|---|
| Inicio | Nuevo caso | Abre expediente vacío |
| Inicio | Pendientes | Abre seguimiento filtrado |
| Casos | Buscar | Filtra expedientes existentes |
| Casos | Nuevo caso | Crea borrador vacío |
| Casos | Abrir | Carga expediente |
| Caso + Informe | Guardar | Persiste el informe |
| Caso + Informe | Analizar | Analiza relato + informe |
| Caso + Informe | Genograma | Edita miembros y vínculos |
| Caso + Informe | Intervención | Crea/edita acciones |
| Análisis | Revisar faltantes | Lleva al campo incompleto |
| Análisis | Ver fuente | Abre metadatos/fuente |
| Análisis | Reanalizar | Ejecuta nuevamente el motor |
| Seguimiento | Nueva tarea | Programa seguimiento |
| Seguimiento | Completar | Cambia estado y registra fecha |
| Recursos | Buscar | Consulta catálogo/motor online si está habilitado |
| Recursos | Guardar | Agrega recurso a biblioteca |
| Biblioteca | Buscar | Busca documentos locales |
| Biblioteca | Importar | Incorpora documento con metadatos |
| Agenda | Abrir | Abre el caso asociado |
| Seguridad | Anonimizar vista | Oculta datos personales |
| Configuración | Guardar | Persiste preferencias |
| Ayuda | Diagnóstico | Muestra comprobaciones locales |

Las acciones destructivas deben requerir confirmación. El flujo de producción no incluye casos de ejemplo.
